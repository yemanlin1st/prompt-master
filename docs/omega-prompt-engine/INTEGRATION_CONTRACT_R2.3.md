## Eight mandatory qualification dimensions
1. Intent and scope: objective, deliverables, exclusions, acceptance.
2. Context and sources: relevance, provenance, freshness, contradictions.
3. Architecture and dependencies: reuse, graph, critical path, interfaces.
4. Domain expertise: sector requirements, applicable standards and limitations.
5. Security and compliance: least privilege, tenant isolation, privacy, licenses, human approvals.
6. Execution and resilience: tool availability, state, retries, idempotence, rollback.
7. Tests and evidence: representative evals, trace IDs, measurable acceptance.
8. Capitalization: versioned decisions, lessons, regression suites.
