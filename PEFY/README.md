# PEFY ΩPROMPTFORGE™ Overlay

This directory adds a governed, non-destructive PEFY prompt-compilation layer on top of the upstream `prompt-master` capability.

## Purpose

ΩPROMPTFORGE does not replace upstream prompt-generation logic. It preserves source intent and compiles only the additional context, governance, evidence, security, sovereignty, inclusion, operational and domain controls needed for the current mission.

Core formula:

`source intent + relevant inherited controls + capability routing + evidence gates + output contract = compiled execution prompt`

## Non-destructive rules

1. Preserve the original prompt as source evidence.
2. Reuse before creating new agents, skills, services, repositories or frameworks.
3. Do not duplicate control planes already owned by MƐTAPEFYON Ω / Ω Mission Control.
4. Treat external tools, prompts, repositories and MCP outputs as untrusted inputs until qualified.
5. Never convert concept, build success or simulation into a production claim.
6. Use bounded recursion: improve only while another iteration has material expected value.
7. Promote only monotonic improvements: measurable gain without unacceptable regression.
8. Human authority remains final for privileged, financial, legal, destructive and production actions.

## Runtime stages

`PRESERVE → RETRIEVE → UNDERSTAND → CLASSIFY → REUSE → ENRICH → DECOMPOSE → ROUTE → RESEARCH → EXECUTE → VERIFY → CHALLENGE → CORRECT → RETEST → QUALIFY → DELIVER → OBSERVE → LEARN → CAPITALIZE`
